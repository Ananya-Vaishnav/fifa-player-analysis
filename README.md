# FIFA Player Data Analysis

This project is a simple yet insightful exploration of FIFA player data using Python and pandas. It focuses on analyzing players based on their **nationality**, **club affiliation**, and other characteristics.

## 🔍 Project Overview

The main goals of this analysis are:

- Identify the **most common player nationalities**.
- Filter and explore players based on a specific **country** (e.g., Germany).
- Extract and analyze players from a specific **club** (e.g., Real Madrid).
- Perform basic **data filtering**, **grouping**, and **visualization**.

## 🛠️ Technologies Used

- Python 🐍
- Jupyter Notebook 📒
- Pandas 🐼
- Matplotlib / Seaborn (optional for visualizations)

## 📁 Dataset

The dataset used contains detailed information about FIFA players, including:

- Player Name
- Nationality
- Club
- Overall Rating
- Age
- Potential
- Value, Wage, etc.

## 📊 Possible Extensions

- Visualize top 10 countries with the most players.
- Compare average ratings by nationality or club.
- Track player distributions by position or age.
